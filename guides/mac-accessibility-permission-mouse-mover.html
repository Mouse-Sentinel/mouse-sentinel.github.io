Mac Accessibility permission for mouse movers

macOS asks before an app can control your pointer. Here is why that permission appears, how to review it, and what to try if automatic cursor movement is not working.

By Mouse Sentinel · Updated September 9, 2026 · 5 minute read

Why a mouse mover needs permission

Accessibility permission is part of macOS privacy protection. It covers apps that control or observe parts of the interface, including software that generates mouse movement. Without the required access, a mouse mover may run its timer while the pointer stays in place.

Mouse Sentinel checks whether Accessibility or macOS post-event access is available. It also performs a tiny move-and-restore test so the app can show whether cursor control is actually working.

How to grant access

  1. Open System Settings.
  2. Choose Privacy & Security.
  3. Select Accessibility.
  4. Find Mouse Sentinel and turn its switch on.
  5. If macOS asks you to quit and reopen the app, do so.
  6. Start Mouse Sentinel and confirm that the permission indicator is green.

The exact labels may change slightly between macOS releases. Mouse Sentinel’s permission button opens the relevant System Settings area for you.

How to remove access

Return to System Settings → Privacy & Security → Accessibility and turn the switch off. You can also remove the app from the list. Mouse Sentinel will no longer be able to create cursor movement until access is granted again.

If cursor movement still does not work

  • Confirm the app is enabled: the main control should say Stop Sentinel and the countdown should be moving.
  • Review Accessibility: turn access off and back on, then reopen the app.
  • Check the current copy: if you moved or replaced the app after granting access, macOS may treat it as a changed build.
  • Wait for inactivity: real keyboard or mouse activity restarts Mouse Sentinel’s countdown.
  • Check compatibility: the current build requires an Apple silicon Mac running macOS 14.0 or later.
  • Ask your administrator: device management can restrict permissions on a work or school Mac.

What this permission does not mean

Accessibility access is powerful, but a permission request alone does not mean an app records your screen, reads files, or sends data over the internet. Those are separate capabilities. You should still install only software you trust and read its privacy information.

Stay in control. Permission should be understandable, visible, and reversible. Mouse Sentinel shows status in the app and only needs cursor-control access for its core function.

Accessibility vs. Screen Recording

Screen Recording permission allows an app to capture visible screen content. A basic mouse mover does not need that permission to change the pointer. Mouse Sentinel does not ask for Screen Recording permission.
